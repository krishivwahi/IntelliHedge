## Important Limitation

This collection uses the English GKG stream.

The language field is inferred from the collection stream, not independently verified for every article.

Therefore:
- This dataset does not represent complete multilingual GDELT coverage.
- Non-English news coverage is outside the scope of this collection.
- Language diversity must be considered when evaluating the dataset.

## Recommendation for IntelliHedge

For the initial prototype, the English stream can be used as the news input.

Future versions may incorporate additional language streams if multilingual coverage is required.

Original records and source information must be preserved.
